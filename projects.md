# Security Projects

A collection of security tools, scripts, and resources developed by the ArmorKeeper community.

A command-line tool for automated security scanning of web applications.

**Features:**
- SQL injection detection
- XSS vulnerability scanning
- Security header analysis
- SSL/TLS configuration checks

All ArmorKeeper projects follow these principles:

- **Open Source**: MIT or Apache 2.0 licenses
- **Documentation**: Comprehensive docs and examples
- **Testing**: Unit tests, integration tests, security tests
