# Services

ArmorKeeper provides hands-on security services for organizations that need more than a scan report.

---

## Penetration Testing

Targeted, manual testing of your applications, APIs, cloud environments, and internal networks. We simulate real-world attack scenarios and deliver findings you can act on — not a 200-page PDF of scanner output.

**Engagements include:**
- Web application and API testing
- Cloud configuration review (AWS, Azure, GCP)
- Internal and external network penetration testing
- Mobile application security assessment

---

## Vulnerability Research

Dedicated research against your products and platforms. We go deeper than a standard pentest, spending focused time on complex attack surfaces where automated tools fall short.

**Typical targets:**
- Custom protocols and binary formats
- Embedded systems and IoT devices
- Authentication and authorization logic
- Third-party integrations and supply chain exposure

---

## Security Advisory

Ongoing partnership with your engineering and security teams. We embed into your development process and help you build it right the first time.

**Advisory covers:**
- Architecture and design review
- Threat modeling
- Secure code review
- Incident response planning
- Security program development
